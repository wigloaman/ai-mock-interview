# AI Mock Interview

A Django web app for practising job interviews with an AI interviewer.

## Planned features

- User profiles and authentication
- Create an interview session for a job role, company and difficulty level
- AI-generated interview questions and cross-questions
- AI review of each answer and an overall interview result
- Answer by voice and hear questions spoken aloud
- Contact and feedback pages

## Tech stack

- Python, Django 5.2

## Getting started

```bash
git clone https://github.com/<your-username>/ai-mock-interview.git
cd ai-mock-interview
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

More setup steps will be added as the project grows.
